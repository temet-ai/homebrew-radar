# Homebrew tap for radar

[radar](https://github.com/temet-ai/radar) is a terminal workspace for GitLab, GitHub,
Jira and Slack, with coding agents beside your work. Install it on macOS or Linux:

```sh
brew install temet-ai/radar/radar
```

Use the full name: Homebrew has an unrelated app called `radar`, and `brew install radar`
installs that one. Upgrade with `brew upgrade temet-ai/radar/radar`.

The formula is rendered from each release's checksums by `scripts/render-homebrew-formula`
in the radar repository. Report problems on [temet-ai/radar](https://github.com/temet-ai/radar/issues).
